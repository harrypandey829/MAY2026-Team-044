Running the Frontend

Hey there! Here is a quick guide on how to get the frontend interface running on your computer.

What you need:
Before starting, make sure you have Node.js installed on your machine. You can download it from their website if you don't have it yet.

Step-by-step setup:

1. Open the project in VS Code.
2. Open your terminal window in VS Code (Ctrl + ~).
3. Move into the frontend folder:
   cd Sports-Club-Management/frontend
4. Install the project packages:
   npm install
5. Start the local server:
   npm run dev

Once that is done, Vite will spin up a local server and give you a link (usually http://localhost:5173 or http://localhost:5174). Ctrl + Click that link to open the app in your browser.

Other commands you might need:
- npm run build: Packages the code for production.
- npm run lint: Checks for code styling and formatting issues.
- npm run typecheck: Checks for any TypeScript compiler errors.
